# PHOENIX — Página corporativa

Sitio web responsive para el proyecto académico PHOENIX, con Vision Mind como producto principal y Nexus como componente de asistente virtual.

## Archivos
- `index.html`: contenido y secciones del sitio.
- `styles.css`: diseño visual, estilos y adaptación a pantallas pequeñas.
- `script.js`: menú móvil, preguntas frecuentes, año automático y validación de demostración del formulario.

## Cómo abrir
1. Descarga o descomprime la carpeta del proyecto.
2. Abre `index.html` en un navegador.
3. Para editar el código, abre la carpeta en Visual Studio Code.

## Antes de publicar
- Reemplaza los campos de correo, dirección y redes sociales por datos oficiales.
- Añade testimonios reales y autorizados si los hay.
- Revisa qué tecnologías y funciones están realmente implementadas.
- El formulario solo valida los campos en el navegador. Para recibir mensajes de verdad, conéctalo a un backend o servicio de formularios y configura la protección de datos.
- El diseño de los proyectos del portafolio es ilustrativo.

## Publicar en GitHub
1. Crea un repositorio en GitHub, por ejemplo `phoenix-vision-mind-web`.
2. Sube `index.html`, `styles.css`, `script.js` y `README.md` a la raíz del repositorio.
3. En GitHub entra a **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`, guarda y espera la publicación.
6. GitHub Pages te mostrará la dirección pública del sitio.

No subas claves API, contraseñas ni credenciales al repositorio.
